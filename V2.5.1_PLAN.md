## 2 — Weight rest-state uses the native placeholder

**Change — LOCKED 2026-08-16**

- Typing replaces it (placeholder vanishes) and enables Save; saving returns it to placeholder. Accepted tradeoff: the old value can't be tap-edited, only retyped.
